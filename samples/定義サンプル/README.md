# ヘッダー定義JSON サンプル集

定義JSONを一から書かなくて済むよう、用途別のサンプルを用意しています。
**使い方：目的に近いファイルをコピーして書き換え → ビューアにドラッグ&ドロップ**（または ⚙設定のテキストエリアに貼り付け）。

| ファイル | 内容 | 合わせて開くサンプルデータ |
|---|---|---|
| `01_最小構成.json` | 必須項目（`match`＋`headers`）だけの最小例。まずはこれをコピーするのが手軽 | `../IF_ORDER_20260705` |
| `02_区切り文字と文字コード.json` | タブ区切り／EUC-JP／複数文字区切り（`@@`）の3定義。`delimiter`・`encoding` の書き方 | `../IF_SHIP_TAB_20260706` `../IF_STOCK_EUC_20260706` `../任意区切りアットマーク.txt` |
| `03_複数行ヘッダーと列詳細.json` | ヘッダー2行＋`details`（マウスオーバーのツールチップ） | `../IF_ORDER_20260705` |
| `04_検査ルール付き.json` | `rules` による検査（必須／日付／数値／正規表現）。「✔ 検査」ボタンでNGセルが赤枠になる | `../IF_ORDER_20260705` |
| `05_固定長レイアウト.json` | `widths`（バイト幅）による固定長分割＋検査。区切り文字なしのCOBOL系IF向け | `../IF_FIXED_20260707` |
| `99_テンプレート.json` | 全項目入りの穴埋めテンプレート。不要な項目は削除して使う | — |

複数の定義を1ファイルにまとめる場合は、`02_区切り文字と文字コード.json` のように配列に並べます。読み込んだ定義はリストの先頭から `match` を照合し、最初に一致したものが自動適用されます（ツールバーの「ヘッダー定義」で切替可能）。

## 項目リファレンス

| 項目 | 必須 | 型 | 説明 |
|---|---|---|---|
| `match` | ✔ | 文字列 | ファイル名のワイルドカード。`*`=任意の文字列、`?`=任意の1文字。大文字小文字は区別しない。例: `"IF_ORDER_*"` |
| `headers` | ✔ | 文字列の二次元配列 | ヘッダー行（外側=行、内側=列）。複数行可。表示層のみでデータには影響しない |
| `name` | — | 文字列 | 定義の表示名。省略時は `match` が表示される |
| `delimiter` | — | 文字列 | 区切り文字の初期値（`","` `"\t"` `"@@"` など複数文字も可）。手動変更が常に優先 |
| `encoding` | — | 文字列 | 文字コードの初期値。`shift_jis` / `utf-8` / `utf-16le` / `utf-16be` / `euc-jp` / `windows-1252` / `ascii`。BOM付きファイルはBOM判定が優先 |
| `details` | — | 文字列の配列 | 列ごとの詳細説明。ヘッダーのマウスオーバーでツールチップ表示。`\n` で複数行 |
| `widths` | — | 数値の配列 | **固定長レイアウトのバイト幅**。指定すると区切り文字ではなくバイト幅で列分割（全角=2バイト等、エンコーディングに応じて計算）。編集モードでは幅が自動維持される |
| `rules` | — | オブジェクトの配列 | 検査ルール。指定すると「✔ 検査」ボタンが表示される（下記） |

### rules の書き方

```json
{ "col": 2, "type": "date", "required": true, "pattern": "^2026" }
```

| 項目 | 説明 |
|---|---|
| `col` | 対象列（**1始まり**）。必須 |
| `required` | `true` で空欄（スペースのみ含む）をNGにする |
| `type` | `"number"`=整数・小数のみ許容 / `"date"`=YYYYMMDD・YYYY-MM-DD・YYYY/MM/DD の実在日付のみ許容（空欄は required でのみ判定） |
| `pattern` | JavaScript正規表現。値全体ではなく部分一致なので、全体を縛る場合は `^…$` で囲む。JSON内では `\d` を `\\d` のように書く |

## 注意

- JSONにはコメントを書けません。メモが必要な場合は `"_memo": "..."` のような未定義キーを足しても動作に影響しません（無視されます）。
- 定義ファイルは **UTF-8** で保存してください（定義JSON自体の文字コード。対象データファイルの文字コードは `encoding` で指定）。
- ドロップで読み込んだ定義は localStorage に保存され次回も有効です（localStorage が使えない環境ではセッション内のみ）。
