❓ 使い方

このツールについて

システム間連携のIFファイル（拡張子なし可）、CSV/TSV、任意区切りテキスト、バイナリファイルを閲覧する読み取り専用ビューアです。元ファイルへの書き込みは一切行いません。

ファイルを開く

  • 画面へドラッグ&ドロップ、または左上の「📂 開く」から選択（複数可）。ファイルはタブで切り替えます。
  • 開いた直後はファイル内容からテキスト/バイナリを自動判定。ツールバーの「モード」でいつでも切替できます。
  • 文字コードは自動判定（BOM＋推定）。化ける場合は「文字コード」で明示指定してください。

テキストモード

  • 区切り：チップをクリックして有効/無効を切替。複数同時に有効化できます（例：「,」＋「空白」）。「＋任意」欄に入力してEnterで任意の区切り文字を登録、登録チップは右クリックで登録解除。
  • 改行：自動判定のほか CRLF / LF / CR を明示指定できます。指定した改行のみで行分割し、他の改行文字はデータとして残ります（␣可視化で ␍ として確認可能）。
  • 表示：グリッド セル分割・区切り非表示／桁揃え 区切りを表示したまま列幅を揃える。
  • 間隔：区切りの後ろに表示上の間隔（0〜16文字）を追加。表示のみでコピーには影響しません。
  • ␣ 可視化：スペース ·、タブ →、全角スペース □、CR ␍ を淡色表示。コピーすると元の文字が得られます。

仮想ヘッダー定義

列の説明行を表示層に重ねる機能です（実データは変更しません）。定義は⚙設定にJSONで登録するか、定義JSONファイルをドロップします。

  • match（ファイル名のワイルドカード）に一致した定義が自動適用されます。複数一致時は先頭優先で、「ヘッダー定義」から切替可能。
  • 定義の delimiter / encoding は開いたときの初期値になり、手動変更が常に優先。BOM付きファイルはBOM判定が優先されます。

マーカー（🖍）

  • テキスト：文字列（Aa切替可）・行番号・列番号（3,10-20 の範囲指定可）をハイライト。色・ON/OFF・件数表示付き。
  • 文字列マーカーは追加フォームの .* ボタンで正規表現マーカーにできます（構文・行単位の扱いは検索と同じ。下の正規表現サンプル参照）。重い正規表現を登録したままにすると再描画が遅くなることがあります。
  • バイナリ：16進バイト列（例 0D 0A）を入力してマーク。HEX側とデコード側の両方に連動します。
  • バイナリには 制御コード候補（STX/ETX/CRLF/NUL等19種）をOFF状態でプリセット済み。折りたたみを開いてONにしてください。

バイナリモード

  • 左からオフセット／HEX（16バイト/行）／指定文字コードでのデコード結果。全角などのマルチバイト文字は先頭バイトの位置に表示され、後続バイトは ·（継続）になります。
  • HEX側・デコード側のクリックで対応箇所を相互ハイライト。マルチバイト文字は全バイトが選択され、ステータスバーに詳細表示。再クリックかEscで解除。
  • 大きいファイルは先頭256KBのみ表示し、末尾の「さらに表示」で追加読み込み。マークや検索の件数はファイル全体を対象に数えます。

検索

  • テキストモードは文字列（Aaで大文字小文字）、バイナリモードは16進パターン（例 0D 0A）。
  • .* ボタンで正規表現検索に切替（VSCodeの検索と同じイメージ）。Aa（大文字小文字）は正規表現でも有効です。
  • 正規表現は行単位で照合します（複数行にまたがる一致はできません）。パターンが不正な場合は件数欄に「無効」と表示されます。
  • Enter/F3で次へ、Shift+F3で前へ。未表示領域のヒットへは表示を拡張してジャンプします。

正規表現サンプル

パターン意味
\d{8}8桁の数字（YYYYMMDD形式の日付など）
^C\d+行頭が「C＋数字」で始まる行（顧客IDなど）
,{2,}カンマの連続（空フィールドの検出）
^,|,$行頭または行末のカンマ
^$空行
\s+$行末の空白（見えないゴミの検出）
[^\x00-\x7F]+非ASCII文字（全角文字・半角カナなど）の連続
TOKYO|OSAKAいずれかの語を含む（OR検索）
^(?!C).「C」で始まらない行（否定先読み）
^([^,]*,){3}94列目が「9」で始まる行（カンマ区切りの場合）

※ JavaScript (ECMAScript) の正規表現構文です。. や | などを文字として検索する場合は \. のようにエスケープするか、通常検索に切り替えてください。

設定の保存について

ヘッダー定義・登録区切り文字・フォント・拡大率などはブラウザの localStorage に保存されます。環境によって localStorage が使えない場合、設定は保存されませんが閲覧機能はすべて動作します（ヘッダー定義はJSONファイルのドロップで代用できます）。
